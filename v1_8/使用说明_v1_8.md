# V1.8 隐藏到托盘

先关闭旧版，再打开桌面“Codex定时唤醒 V1.8”或 `dist/Codex定时唤醒_v1_8.exe`。计划、消息与聊天绑定自动继承 V1.7；新设置独立保存在 `%LOCALAPPDATA%\CodexAlarm\v1_8`，旧文件保留。

## 使用

1. 核对计划，点击“开启定时”。
2. 点击右上角“隐藏到托盘”。窗口和任务栏窗口入口隐藏，定时继续运行。隐藏不会自动开启原本暂停的计划。
3. 在 Windows 右下角托盘找到蓝色时钟图标，点击或双击恢复；也可右键选择“显示窗口”。图标可能位于托盘的折叠区域，展开小箭头可见。
4. 右键选择“退出程序”可退出，退出前保留已有的运行中保护与定时确认。若取消退出，窗口恢复显示，程序继续运行。右上角关闭按钮仍按原方式退出。

托盘图标的悬停文字显示“已暂停”或“定时已开启”，开启时附下次发送时间；正在处理时附处理状态。恢复窗口后移除托盘图标，避免重复入口。再次隐藏时重新显示同一个图标。

隐藏前先确认 Windows 成功添加图标；添加失败则保留可见窗口。Windows 资源管理器重新创建托盘时，程序会尝试恢复图标，失败时恢复窗口，避免无法找回。退出时自动清理图标与图标资源。

托盘功能不会唤醒睡眠电脑，也没有增加开机启动。保持电脑开机联网；启动程序默认暂停。

没有真实发送或调用模型。Windows 托盘的实际点击和真实定时发送请用户试用验收。

Windows 实现依据：[Shell_NotifyIconW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shell_notifyiconw)、[NOTIFYICONDATAW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/ns-shellapi-notifyicondataw)。
