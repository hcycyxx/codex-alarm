# Codex 定时唤醒 V1

双击“Codex定时唤醒_v1.exe”，无需安装 Python。

1. 点击“检查连接”。此操作只检查本机 Codex 登录、模型和聊天接口，不发送消息。
2. 滚动或拖动小时、分钟；也可以聚焦后用上下方向键。默认每天 05:00。
3. 写好发送内容。默认“只回复 OK。”。
4. 点“开启定时”，保持电脑开机、联网，程序可以最小化。首次到点发送时自动创建专用“定时唤醒”聊天，以后复用，不触碰工作聊天。
5. 要先验证，可点击“立即试发…”，核对弹窗内容后确认发送。发送完成后在 Codex 工作面板查找“定时唤醒”；若列表未更新，请重新进入项目或重开桌面软件查看。

## 运行方式

- 使用本机 Codex 官方 app-server 接口，与桌面软件共用聊天目录和当前配置；优先使用最新已安装桌面版的配套程序。固定选择 GPT-6.1 Sol，不自动改账号、服务或用户配置。
- 只接受 ChatGPT 登录模式，不使用 API Key 登录模式。保留现有服务配置；若用户自行配置代理，仍走该配置。程序不保存账号凭据。
- 每次启动默认暂停；需点击“开启定时”。设置和聊天绑定会记住，修改时间、重复方式或内容后需重新开启。
- 错过超过 2 分钟则跳过，不会在睡眠恢复后突然补发。关机或退出期间不会执行；没有后台安装、开机启动或系统任务。
- 失败或结果不明时不自动重发。下一次日常定时仍按计划执行。记录区区分连接、消息提交、模型完成，不把“已提交”当成“完成”。
- 用户自定义消息会发给模型；专用聊天限制为简短回复，不执行工具任务。
- 单实例运行，避免打开多个窗口重复发送。正在处理时不能关闭窗口，最长等待约 4 分钟。
- 软件只负责定时发消息，额度实际显示和重置以 Codex 为准。

## 文件

设置以新快照保存，旧文件不覆盖；记录和专用工作目录位于 `%LOCALAPPDATA%\CodexAlarm\v1`。记录不写消息正文、账号或其他工作聊天内容。

## 交付验证范围

已只读验证本机 ChatGPT 登录、GPT-6.1 模型及与桌面聊天目录互通；开发过程中未调用模型、未发送真实消息。真实发送、首次聊天创建、桌面显示和额度效果由用户“立即试发”验收。不要把本地检查视作实际发送成功。
